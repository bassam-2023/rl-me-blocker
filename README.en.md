# RL ME Blocker

**[العربية](README.md)**

Stops Rocket League from putting you on **Middle East (ME6)** servers. One click to block, one click to allow.

<p align="center"><img src="docs/screenshot-en.png" width="340" alt="RL ME Blocker window"></p>

## Install

1. Download it from [**here**](https://github.com/bassam-2023/rl-me-blocker/releases/latest) and extract it (right-click → Extract All).
2. Double-click **`Install.cmd`**.
3. If you see *Windows protected your PC*, click **More info → Run anyway**, then **Yes**.

After installing, you can delete the download and the extracted folder.

## Use

Open **RL ME Blocker** from your Desktop, then click **Block** or **Allow** **before** you queue.

## Uninstall

**Settings → Apps → RL ME Blocker → Uninstall.**

## FAQ

**Can I get banned?** It never touches the game. It only adds a Windows Firewall rule. Use at your own risk.

**Warning that another program manages your firewall?** Your antivirus (e.g. Norton) replaces Windows Firewall, so blocking won't work until Windows Firewall is turned back on.
